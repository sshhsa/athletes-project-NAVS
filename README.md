# Спортсмени НАВС — проєкт

Веб-застосунок для обліку спортсменів НАВС: список у вигляді таблиці/плитки та
детальна картка спортсмена. Референс дизайну — три екрани, підготовлені у Figma
(див. docs/screens-reference).

## Структура

- `frontend/` — семантична html/css вёрстка трьох екранів (крок 1)
- `backend/` — Express + MongoDB API (крок 2)
- `docs/` — довідкові матеріали, скріни макету

## Статус

- [ ] Крок 1 — фронтенд (семантичний html/css)
- [ ] Крок 2 — бекенд (Express/MongoDB/auth/mail/upload)
- [ ] Крок 3 — інтеграція фронт+бек
- [ ] Крок 4 — адаптивна вёрстка

## Технології

**Frontend:** HTML5, CSS3 (спочатку без фреймворків; React — опційно пізніше)
**Backend:** Node.js, Express, MongoDB (Mongoose), JWT, Nodemailer, Multer/Cloudinary, Joi
